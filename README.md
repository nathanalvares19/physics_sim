# Physics Simulator

A simple implementation of a physics simulator in C++

## Requirements

- Windows 10 / 11
- MSYS2 installed
- Use **MSYS2 MinGW64** shell

---

## Install raylib

Open **MSYS2 MinGW64** and run:

```bash
pacman -S mingw-w64-x86_64-raylib
```

Verify:

```bash
ls /mingw64/include/raylib.h
```
